# Quota Desk

Codex・Claudeの利用量／残量を確認するWindows向けツールです。

## ダウンロード

最新版はGitHub Releasesからダウンロードできます。

https://github.com/sideen/quota-desk/releases/latest

「Assets」から「Quota-Desk-」で始まるZIPファイルをダウンロードしてください。

GitHubが自動表示する「Source code (zip)」「Source code (tar.gz)」は、Quota Desk本体ではありません。

## 対応環境

Windows 10／11 x64を想定しています。

すべてのWindows環境での動作を確認したものではありません。

## 注意事項

配布しているEXEにはデジタル署名を付けていないため、Windows SmartScreenなどの警告が表示される場合があります。

詳しい使い方や注意事項は、配布ZIP内の「はじめにお読みください.txt」を確認してください。
